## 资格自查：这几种情况会让你领不了，或者领了也白费

申请被拒，绝大多数时候出在资格上。下面这几条在提交之前就能核对完。

- **买过 0 元的也算老用户。** 官方对“产品新用户”的定义是：该产品下没有大于等于 0 元的新购订单、没产生过大于等于 0 元的后付费账单、历史上没有试用订单。哪怕你之前领过一台 0 元活动机，这台 ECS 的试用资格也没了。
- **同类产品只能领一种规格。** 试用过 s6 1核2G，就不能再去领 c7 2核4G——规格不同也算同一类产品。
- **换手机号重新注册没用。** 同一用户只能对同一类产品申请一次试用，系统按人识别，新账号躲不过。
- **先领试用，再开通服务。** 试用资源必须在服务功能开通之前领取。一旦你先从别的入口开通了 ECS，系统会自动把你识别成非新用户，想领都领不了。
- **欠费先补齐。** 账号有欠费记录，补足之前领不了。
- **虚商账号和 RAM 子账号不能参加。** 得用主账号、注册会员身份申请。
- **个人身份试用过或买过，升级成企业账号也不能再试。** 想用企业规格的，注册第一天就做企业认证，别来回折腾。
- **必须从免费试用中心页面领取。** 从产品详情页或控制台进去开通，享受不到试用权益。

## 试用到期前后：计费、数据和最容易吃亏的几件事

试用本身不花钱，容易产生费用的地方在额度之外和到期之后。到期前阿里云会通过邮件和站内信提醒你，接下来怎么处理取决于实例的计费模式：

## 常见问题

**试用时间可以延长吗？**
不行。每个账号每款产品只有一次试用机会，时长也无法延长。到期后要么续费，要么及时清理资源，别放着不管。

**为什么提示我无法试用？**
按顺序排查：实名认证做了没有；这个产品以前试用过或买过没有；有没有同人账号已经参加过活动；是不是从免费试用中心页面进去开通的。四个都没问题按钮还是灰的，把鼠标停在按钮上看系统给的具体原因。

**到期后数据还在吗？**
保留 1~15 天，具体时长看各产品规则。超时未续费，实例释放、数据清理，过期前做好备份。

**试用结束后再买，还算新用户价吗？**
按官方试用页面的说法，试用结束后购买仍可享受新用户优惠价格。先试用再决定，不会损失折扣资格。

**不想自己搭环境怎么办？**
